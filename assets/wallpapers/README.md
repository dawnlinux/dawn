# Wallpapers

Images placed here are copied into `~/Pictures/Wallpapers` by `install.sh`,
which is where the island's wallpaper carousel reads from (`wallpaperDir` in
`config/quickshell/dawn-island/Config.qml`).

Dawn ships none by default. Wallpapers are large binary files that would
dominate the repository's size and history, and the accent colour is derived
from whatever you choose anyway (`dawn-island/services/Accent.qml`) — so any
image works and none is privileged.

Drop your own in here if you want `install.sh` to seed them on a new machine.
